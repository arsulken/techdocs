# Первоначальная версия интерфейса

Снимки в этой папке относятся к первой версии проекта со светлой темой и использовались в первоначальном отчёте. Текущий интерфейс переведён в тёмную тему, а каталог дополнен пятью инструкциями. Для просмотра актуального результата запустите проект по инструкции в корневом README.md.
